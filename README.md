# Sales MIS & Business Performance Dashboard

## Project Overview
This project demonstrates an end-to-end Sales Management Information System (MIS) developed using Google Sheets. It uses a fictional retail sales dataset to analyse sales performance, monitor business operations and generate management reports.

## Dataset Overview
- 600 sales transactions
- 5 sales regions
- 20 products
- 147 unique customers in the transaction data
- 10 sales representatives
- Reporting period: January–June 2026

## Key Features
1. Data cleaning and validation
2. Sales calculations and revenue analysis
3. Daily and monthly MIS reporting
4. Region-wise sales performance analysis
5. Product-wise sales analysis
6. Salesperson performance tracking
7. KPI-based management dashboard
8. Monthly sales trend and top-selling product visualisations

## Tools & Functions Used
**Google Sheets:** Data Cleaning, Data Validation, Conditional Formatting, Charts, Dashboard Design.

**Functions:** IF, IFERROR, SUMIF, SUMIFS, COUNTIF, COUNTIFS, FILTER, UNIQUE, SORT, QUERY, VLOOKUP, DATEVALUE, EDATE and ARRAYFORMULA.

## Project Objective
To demonstrate practical MIS reporting, spreadsheet-based data analysis, reporting automation and business performance monitoring skills.

*Note: The dataset contains fictional business and customer information created for learning and portfolio purposes.*
